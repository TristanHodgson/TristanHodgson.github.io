What I Use

My Laptop is a ASUS Vivobook S14 M3407HA with and AMD Ryzen 7840HS, 32GB of RAM, 1TB NVMe SSDs. I run Cachy OS with the Hyprland window manager.

I also have a mini PC that I use as a server; it is a Beelink EQR6 Mini PC with an AMD Ryzen 7 6800U, 32GB RAM and a 1TB NVME SSD. On this server I run ubuntu server with various docker containers hosting some services:

  • Syncthing: syncing files between my server, and the two different SSDs on my dual boot
  • Duplicati: backup for my data (to my UNI OneDrive); the nice thing about this is that I don't need to worry about backing up my laptop as everything is synced and backed up
  • Nextcloud: I add the SMB shares to this using the external storage addon; I don't really use it for storage but some of the addons are good
  • Home Assistant: I have a couple of smart lights that I control through this without them needing to connect to the internet
  • Paperless-ngx: handles all my important documents
  • SearXNG: a privacy-respecting metasearch engine

In terms of peripherals, I use a Logitech MX Master 3s mouse and an NZXT Function TKL keyboard (though I don't think I could recommend this). I also use a ASUS XG27ACS 27 inch 2560x1440 180Hz monitor, this is massively overkill for my use case however my college bought it for me and I am very happy with it.
